# V6.8 境界突破

本版目标：一个核心玩法系统 + 一个视觉系统。

- 核心玩法：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘的局内突破。
- 每次大境界提供 3 个不可逆道基选择，改变伤害、暴击、施法、领域、召唤、生存等规则。
- 视觉系统：Overlay 淡入淡出、卡牌微动效、境界突破专属界面、下境进度与境界光晕。
- 六道法宝共鸣继续保留并与境界能力叠加。

QA：两个 script block 均通过 `node --check`；静态检查未发现缺失的 `this.method()` 或 UI id。容器无可用 EGL/WebGL 环境，因此没有声称 headless 视觉截图 QA 通过。
