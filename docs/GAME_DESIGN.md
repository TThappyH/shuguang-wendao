# 《曙光问道》V7 总设计纲要

## 1. 核心定位

《曙光问道》是一款明亮东方玄幻 / 修仙题材的 Survivors-like 浏览器肉鸽。

单局体验：

> 从炼气小修士进入秘境 → 斩妖吸收灵气 → 悟功法、炼灵器、夺法宝 → 境界突破 → 经历天劫 → 挑战妖王、道君、剑尊 → 形成独特修仙流派。

核心区别不是“幸存者 + 中文名”，而是把 **境界、功法、法宝、道途、天劫、秘境** 变成单局结构的一部分。

---

## 2. 单局节奏

目标时长：18～22 分钟。

| 时间 | 阶段 |
| --- | --- |
| 0～3 分钟 | 炼气 · 熟悉基础流派 |
| 3 分钟 | 第一秘境 Boss |
| 3～6 分钟 | 筑基 · Build 初成 |
| 6 分钟 | 第二 Boss |
| 6～9 分钟 | 金丹 · 灵器开始蜕变 |
| 9 分钟 | 第三 Boss |
| 9～12 分钟 | 元婴 · 法宝共鸣 |
| 12 分钟 | 第四 Boss |
| 12～15 分钟 | 化神 · 高阶妖潮 |
| 15 分钟 | 第五 Boss |
| 15～18 分钟 | 炼虚 · 极限 Build |
| 18 分钟 | 最终秘境之主 |
| 18+ | 无尽 / 天劫模式 |

单局结构：

> 境界 → 妖潮 → Boss → 突破 → 新秘境 → 更高境界

---

## 3. 五条成长线

### 3.1 灵器 / 术法

相当于主动武器，最多 6 件。

候选：

- 青竹剑阵
- 五雷正印
- 南明离火
- 太阴月轮
- 乾坤吞灵阵
- 灵鹤剑侍
- 玄冰法环
- 山河印
- 万魂幡
- 斩仙飞刀
- 紫霄神雷
- 九龙神火罩

成长：

> Lv1 → Lv5 → 蜕变 → 本命形态

例：

> 青竹剑阵 → 万竹剑海 → 搭配「先天剑心」→ 诛仙剑域

升级不只做伤害数值，而要改变数量、轨迹、分裂、穿透、剑气、领域、召唤等行为。

### 3.2 功法

相当于被动构筑，最多 6 门。

候选：

- 太上养气诀
- 九转金身诀
- 紫霄雷经
- 太阴真经
- 大日焚天诀
- 万剑归宗
- 青帝长生诀
- 鲲鹏身法
- 洞玄天眼
- 周天星辰诀

功法负责定义流派，而不是只提供小额百分比。

### 3.3 法宝

法宝必须“改规则”，而不只是高级被动。

例：

- 乾坤袋：Boss 多掉宝物、宝箱出现双选、提升高阶法宝率
- 摄魂铃：精英死亡收魂，达到阈值不断进化
- 九转涅槃羽：复生、火凤清屏、渡劫强化

### 3.4 天材地宝 / 丹药 / 符箓

主要负责战场即时爽感。

丹药：回春丹、筑基丹、龙虎丹、九转金丹

符箓：镇妖符、神行符、金刚符、天雷符、遁地符

灵物：青莲露、龙髓、朱果、悟道茶、凤凰真血、星辰砂

### 3.5 境界

正式境界：

> 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘

突破时出现真正的分支选择，而不是简单等级映射。

例：筑基三选一：

- 天道筑基：均衡强化
- 剑道筑基：剑类灵器强化
- 五雷筑基：雷法获得连锁机制

金丹可形成一品剑丹、九纹雷丹、大日金丹等。

元婴阶段可决定元婴法相。

## 4. 六大道途

第一阶段固定六条主流派：

### 剑道

飞剑、剑阵、暴击、穿透。

### 雷法

连锁、麻痹、天雷、雷劫。

### 火法

燃烧、爆炸、持续地火。

### 阵道

领域、阵眼、范围控制。

### 御灵

灵兽、剑侍、灵鹤、召唤物。

### 炼体

气血、护体、反伤、近战。

所有灵器、功法、法宝逐步添加 Tag，并通过 Tag 触发共鸣。

## 6. 地图区域

不再长期依赖单一无限草坪。

推进顺序：

1. 青云山麓：竹林、石阶、小溪、桃花
2. 百兽山：巨树、瀑布、兽骨、妖寨
3. 丹霞谷：红岩、丹炉、药田、灵火
4. 九霄雷泽：浮石、雷池、云海
5. 昆仑仙墟：白玉宫殿、断桥、仙鹤、悬浮山
6. 太虚天门：云海、巨大阵法、天门、星河

目标感受：

> 玩家从山脚一路打到天上。

---

## 7. 美术方向

固定：

> 中国青绿山水 + Stylized 3D + 动画电影感

主色：

- 青绿
- 天青
- 玉白
- 金色
- 少量朱砂

避免：

- 黑紫暗黑统一滤镜
- 纯靠 Glow 提升质感
- 大量通用球体/圆柱堆角色
- UI 与世界材质语言脱节

主角最终应彻底仙侠化：长发 / 发冠、宽袖、大披风、腰间葫芦、悬浮飞剑、本命灵器，不再保持西式弩手游侠的核心轮廓。

---

## 8. UI 总方向

材质语言：

> 宣纸 / 温玉 / 铜 / 金线 / 朱砂印 / 云纹 / 八卦纹

但战斗 HUD 必须克制。

布局目标：

- 顶部：极细悟道经验条
- 左上：人物头像、境界、气血
- 顶部中央：时间、秘境名称
- 右上：灵石、击杀、乾坤宝录、暂停
- 底部中央：6 个本命灵器槽
- 左下：最多 8 个关键法宝图标
- 复杂信息进入升级、突破、宝箱、图鉴、暂停界面

UI 设计原则：

> 游戏界面，不是网页 dashboard。

## 10. 设计检查

任何新增内容必须先问：

1. 有没有修仙味？
2. 有没有真正改变玩法？
3. 看起来值不值得玩家停下来多看一眼？

三个都没有，就不加。
