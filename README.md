# 曙光问道

一个正在迭代中的 **东方玄幻 / 修仙题材 Survivors-like 浏览器肉鸽**。

当前版本：**V6.7 · 法宝共鸣**

## 核心定位

《曙光问道》不是“幸存者换一套中文名字”，而是逐步把 **境界、功法、灵器、法宝、道途、天劫、秘境推进** 真正做进单局循环。

单局目标体验：

> 炼气小修士进入秘境 → 斩妖吸收灵气 → 悟功法、炼灵器、夺法宝 → 境界突破 → 经历天劫 → 挑战妖王 / 道君 / 剑尊 → 形成独特修仙流派。

## 美术方向

固定为：

> 青绿山水 + Stylized 3D + 玉白仙宫 + 云海 + 竹林 + 灵泉 + 金色阵纹 + 青蓝灵气 + 少量朱砂

不走暗黑黑紫路线，也不依靠 Glow 掩盖造型问题。

## 当前版本内容

- 明亮东方幻想场景
- 高位俯视 Survivors 视角
- 9 件灵器 / 术法
- 12 门基础功法属性
- 24 件法宝 / 天材地宝
- 六大道途 2 / 4 件法宝共鸣：剑 / 雷 / 火 / 阵 / 御灵 / 炼体
- 乾坤宝录与道韵进度统计
- 宝匣鉴宝道韵联动预览
- 6 个正式 Boss
- 多种精英与普通敌人
- 道具掉落、宝匣、丹药、符箓
- 法宝品阶：玄 / 地 / 天 / 仙
- 境界显示：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘

## 运行

直接打开 `index.html` 即可运行。

> 当前版本通过 CDN 加载 Three.js 与 GSAP，因此需要联网。

## 开发原则

每次新增内容先问三件事：

1. 有没有修仙味？
2. 有没有真正改变玩法？
3. 看起来值不值得玩家停下来多看一眼？

三个都没有，就不加。
