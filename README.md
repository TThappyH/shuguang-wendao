# 曙光问道

一个正在迭代中的 **东方玄幻 / 修仙题材 Survivors-like 浏览器肉鸽**。

当前版本：**V8.1 · 灵脉争夺战**

当前开发分支：`dev/v8-spirit-vein-encounters`

## 核心定位

《曙光问道》不是“幸存者换一套中文名字”，而是逐步把 **境界、功法、灵器、法宝、道途、天劫、秘境推进** 真正做进单局循环。

单局目标体验：

> 炼气小修士进入秘境 → 斩妖吸收灵气 → 悟功法、炼灵器、夺法宝 → 境界突破 → 经历天劫 → 挑战妖王 / 道君 / 剑尊 → 形成独特修仙流派。

## 美术方向

固定为：

> 青绿山水 + Stylized 3D + 玉白仙宫 + 云海 + 竹林 + 灵泉 + 金色阵纹 + 青蓝灵气 + 少量朱砂

不走暗黑黑紫路线，也不依靠 Glow 掩盖造型问题。

## 运行

通过任意静态 HTTP 服务打开仓库根目录的 `index.html`，例如 GitHub Pages、VS Code Live Server 或：

```bash
python -m http.server 8000
```

当前 `index.html` 会加载 `runtime/v6.7/` 下的压缩版本快照；V8 Foundation 的新增逻辑已固化在该运行快照中。游戏本体仍通过 CDN 加载 Three.js 与 GSAP，因此需要联网。

## 迭代方式

后续版本按以下流程推进：

> Issue → `dev/...` 开发分支 → 实现与检查 → Pull Request → 合并 `main` → `releases/` 保留版本快照

当前开发任务是 V8.1：验证灵脉目标是否真正改变移动路线与风险选择，再根据人工单局记录调整出现频率、占领时间和剑势收益。

## 开发原则

每次新增内容先问三件事：

1. 有没有修仙味？
2. 有没有真正改变玩法？
3. 看起来值不值得玩家停下来多看一眼？

三个都没有，就不加。
